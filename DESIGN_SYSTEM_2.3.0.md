# MiAula Dark — Design System 2.3.0

Inspiración: Dala / Refero, adaptada a un producto docente de alta densidad de información.

## Tokens principales
- Canvas: `#000000`
- Surface 1: `#0B0B0D`
- Surface 2: `#121216`
- Surface 3: `#18181D`
- Elevated: `#202027`
- Border: `rgba(255,255,255,.08)`
- Text: `#FFFFFF`
- Secondary text: `#A1A1AA`
- Tertiary text: `#71717A`
- Primary: `#8052FF`
- Primary hover: `#936EFF`
- Success: `#15846E`
- Warning: `#FFB829`
- Danger: `#F05D6D`

## Principios
1. Negro como lienzo principal; superficies oscuras solo para agrupar información.
2. Violeta reservado para acción primaria, selección y foco.
3. Liquid Glass solo en navegación, contexto y modales.
4. Tablas y cuaderno usan superficies opacas para máxima legibilidad.
5. Radio estándar 18–24 px; pills para acciones y segmentados.
6. Sin sombras decorativas pesadas; profundidad por contraste, borde y blur.
7. Tipografía Inter cuando esté disponible; fallback del sistema para preservar uso offline.
8. Controles táctiles de ~44 px o más.
9. Nunca texto claro sobre superficie clara ni texto oscuro sobre superficie oscura.
